# Andrea-Calendar-App

Distribuzione pubblica compilata di Andrea Calendar.

## Apri l'app

https://adonato1996-ux.github.io/Andrea-Calendar-App/

Questo repository contiene soltanto la build finale necessaria per GitHub Pages. Il codice sorgente, i test e la documentazione di sviluppo restano nel repository privato `Andrea-Calendar`.

## Installazione iPhone

Apri il link in Safari, usa **Condividi → Aggiungi alla schermata Home** e avvia la PWA dalla nuova icona.

I dati degli eventi sono salvati localmente in IndexedDB. La PWA include inoltre **Crea backup** e **Ripristina** per conservare una copia JSON separata, salvabile in File/iCloud Drive.
